# ADR-0003: المعمارية الطبقية النظيفة وفصل النواة الفيزيائية (Clean Layered Architecture)

## الحالة (Status)
معتمد (Accepted)

## السياق (Context)
تحتوي منظومة كواشف على معادلات فيزيائية معقدة مستمدة من معايير IAEA (مثل حساب FWHM، تصحيح الاضمحلال الإشعاعي، معادلات الكفاءة، ومعايير المطابقة). خلط هذه المعادلات مع أكواد واجهات PyQt6 أو أكواد استعلامات SQLite يجعل اختبارها آلياً أمراً بالغ الصعوبة ويؤدي لتشابك الأخطاء.

## القرار (Decision)
اعتماد معمارية طبقية نظيفة صارمة (Strict Clean Layered Architecture) تنقسم إلى الحزم التالية داخل جذر `kashif/`:
1. **طبقة النواة الفيزيائية (`kashif/core/`):** كود نقي ومستقل بنسبة 100% عن أي مكتبة واجهة مستخدم (PyQt) أو قاعدة بيانات (SQLite). تحوي نماذج البيانات المجردة، معادلات IAEA، حساب الاضمحلال، وقواعد القرار (Rules Engine).
2. **طبقة الخدمات والأمان (`kashif/services/`):** التوثيق، إدارة الجلسة، تشفير كلمات المرور، والتحقق من الصلاحيات.
3. **طبقة البيانات والتخزين (`kashif/db/`):** جداول SQLite، سجل التدقيق المنيع (Immutable Audit Log)، والنسخ الاحتياطي.
4. **طبقة التقارير والتصدير (`kashif/reports/`):** بناء تقارير PDF عبر ReportLab وتصدير Excel.
5. **طبقة واجهة المستخدم (`kashif/gui/`):** شاشات PyQt6، معالجات الفحص الإرشادية (Wizards)، الرسوم التفاعلية، والسمات.

## النموذج المرجعي (RadRiskMap)
تطبق منظومة RadRiskMap نفس الفصل الحازم بين الحسابات الإشعاعية (`radriskmap/core/`) وطبقة الواجهات والخرائط، مما أتاح اختبار النواة الفيزيائية بالكامل بمعزل عن بيئة الواجهة الرسومية عبر `pytest`.

## البدائل المدروسة وأسباب استبعادها (Alternatives Considered)
1. **المعمارية الأحادية المتداخلة (Monolithic UI-Centric Script):**
   - *سبب الاستبعاد:* كتابة المنطق الفيزيائي داخل دوال معالجة الأحداث (Event Handlers / Qt Slots)؛ هذا أسلوب رديء وسريع الانهيار، ويستحيل تغطيته باختبارات آلية مستقلة.
2. **المعمارية الموجهة بالخدمات المصغرة (Microservices):**
   - *سبب الاستبعاد:* تعقيد تقني غير مبرر لمنظومة مكتبية أحادية المستخدم في معمل نووي مستقل.

## العواقب (Consequences)
- إمكانية تحقيق نسبة تغطية اختبارات آلية تتجاوز 90% للنواة الفيزيائية بسهولة تامة.
- سهولة تطوير الواجهة أو استبدال عناصر الرسوم دون المساس بالحسابات الفيزيائية المعتمدة.
