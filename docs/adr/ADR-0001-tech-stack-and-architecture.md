# ADR-0001: اختيار المنصة ولغة التطوير لمنظومة «كاشف» (KASHIF-QA)

## الحالة (Status)
معتمد (Accepted)

## السياق (Context)
منظومة «كاشف» هي نظام برمجيات معملي متخصص في مراجعة وضبط جودة كواشف الإشعاع النووي (HPGe و NaI(Tl)) وسلسلة القياس الإلكترونية، وفق معايير الوكالة الدولية للطاقة الذرية IAEA MRNI-507. تتطلب المنظومة:
1. دقة رياضية وفيزيائية فائقة في حسابات الطاقة، دقة التحليل (FWHM)، ومعاملات الاضمحلال الإشعاعي.
2. العمل التام والمستقل داخل المعامل النووية دون اتصال بالإنترنت (Offline-First).
3. واجهة مستخدم رسومية حديثة تدعم اللغة العربية والإنجليزية باتجاه صحيح (RTL/LTR).
4. سرعة معالجة الرسوم البيانية للأطياف متعددة القنوات وإشارات راسم الذبذبات.

## القرار (Decision)
اعتماد **Python 3.10+** كلغة تطوير رئيسية، مع إطار العمل المكتبي **PyQt6** لبناء واجهة المستخدم الرسومية.

## النموذج المرجعي (Reference Architecture - RadRiskMap)
تسترشد منظومة «كاشف» بالنموذج المرجعي لمنظومة **RadRiskMap** المطورة للمركز؛ حيث أثبتت بنية (Python + PyQt + SQLite + ReportLab) قدرة فائقة على:
- إدارة السجلات النووية والإشعاعية المحلية بأمان وسرعة.
- توفير واجهات عربية أصيلة ومنسقة تماماً مع المعايير المؤسسية.
- إنتاج تقارير PDF معتمدة خالية من أي تشوهات لغوية أو خطية.

## البدائل المدروسة وأسباب استبعادها (Alternatives Considered)
1. **تطبيقات الويب المستضافة محلياً (Local Web: React / Vue / Fastify):**
   - *سبب الاستبعاد:* تتطلب تشغيل خادم ويب وخادم قاعدة بيانات وفتح منافذ شبكية محلية على جهاز المعمل، مما يزيد من تعقيد التثبيت وإدارة العمليات في الخلفية، ويجعل التعامل مع الملفات والطباعة المحلية والرسوم اللحظية أكثر تعقيداً في بيئة معملية مغلقة.
2. **تطبيقات إلكترون (Electron + JavaScript):**
   - *سبب الاستبعاد:* استهلاك مفرط للذاكرة وموارد المعالج، وضعف بيئة الجافاسكريبت الأصلية في المعالجات الفيزيائية الدقيقة مقارنة بحزم بايثون العلمية المتخصصة.
3. **تطبيقات سطح المكتب .NET / WPF (C#):**
   - *سبب الاستبعاد:* بيئة ممتازة لأنظمة ويندوز، ولكن منظومة كواشف تتطلب معالجة مستمرة للبيانات الطيفية والخوارزميات الفيزيائية، وتملك بايثون مكتبات علمية ونووية لا تضاهى، فضلاً عن رغبة الفريق في توحيد المهارات التقنية مع منظومة RadRiskMap المعتمدة.

## العواقب (Consequences)
- استقلالية تامة، سهولة صيانة واختبار النواة الفيزيائية، وتحزيم متكامل عبر PyInstaller لاحقاً.
