# ADR-0001: اختيار المنصة والمعمارية لمنظومة «كاشف» (KASHIF-QA)

## السياق (Context)
المطلوب بناء منظومة رقمية لإجراءات فحص وضبط جودة كواشف الإشعاع النووي (HPGe و NaI(Tl)) وفق معايير الوكالة الدولية للطاقة الذرية (IAEA MRNI-507). المنظومة ستعمل داخل معامل القياسات الإشعاعية والنووية، وتحتاج إلى دقة حسابية فيزيائية عالية، والعمل التام دون اتصال بالإنترنت، وواجهة رسومية ثنائية اللغة، وإصدار تقارير معتمدة بدقة متطابقة مع الاستمارات الدولية.

## القرار (Decision)
تم اتخاذ القرارات المعمارية التالية:
1. **المنصة واللغة:** استخدام **Python 3.10+** مع إطار واجهات المستخدم **PyQt6** كتطبيق مكتبي مستقل (Desktop Standalone).
2. **قاعدة البيانات:** استخدام محرك **SQLite** مدمج محلياً مع تفعيل وضع `WAL` لدعم الأداء العالي وموثوقية المعاملات.
3. **نمط المعمارية:** تطبيق المعمارية متعددة الطبقات (Layered Architecture):
   - `core/`: النواة الفيزيائية ومعادلات IAEA المجردة وقواعد التحقق واضمحلال النظائر.
   - `db/`: الاتصال والجداول وسجل التدقيق وإدارة التخزين.
   - `reports/`: توليد تقارير PDF عبر ReportLab وتصدير Excel.
   - `gui/`: واجهات PyQt6، معالجات الفحص، والرسوم البيانية.
4. **محرك التقارير:** اعتماد **ReportLab** كمعيار لبناء ملفات PDF مطابقة لاستمارة IAEA Annex II.
5. **النموذج المرجعي:** الاسترشاد بالمعايير الهندسية والتصميمية لمنظومة **RadRiskMap**.

## العواقب (Consequences)
- **الإيجابيات:**
  - استقلالية كاملة عن الشبكة وخوادم الويب الخارجية.
  - قدرة هائلة في التعامل مع الحسابات الرياضية والتحليل الطيفي ومعادلات الاضمحلال.
  - واجهة حديثة قابلة للتخصيص الكامل ودعم حقيقي لليمين-إلى-اليسار (RTL) بالعربية.
  - سهولة اختبار النواة الفيزيائية آلياً بمعزل تام عن الواجهة الرسومية عبر `pytest`.
- **الالتزامات:**
  - توفير بيئة تشغيل بايثون والاعتماديات أثناء التوزيع عبر أداة تحزيم مثل PyInstaller لاحقاً.
