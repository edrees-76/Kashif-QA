# خطة المهام والمراحل لمنظومة «كاشف» (KASHIF-QA)
## Phased Implementation Roadmap & Tasks

- **الإصدار:** 1.0.0-draft
- **الحالة:** معروض للاعتماد (Gate G1)
- **منهجية العمل:** دورات بناء مغلقة (Phases)؛ لا يبدأ Phase حتى يجتاز سابقه البوابة G3 (اختبار يدوي ناجح + مراجعة كود + دمج مؤكد).

---

## ملخص المراحل (Phases Overview)

| المرحلة | الوصف | المخرجات الرئيسية |
| :--- | :--- | :--- |
| **Phase 0: Skeleton** | الهيكل العظمي والبنية الأساسية | مشروع يعمل من البداية للنهاية، نافذة بشعار كاشف، اتصال SQLite، أول اختبار. |
| **Phase 1: Core Physics & Registry** | النواة الفيزيائية وسجل الكواشف والمصادر | معادلات IAEA، حساب الاضمحلال، شاشات إدارة الكواشف والأجهزة والمصادر، واختبارات الوحدة. |
| **Phase 2: HPGe Diagnostic Wizard** | معالج فحص كواشف الجرمانيوم التفاعلي | مسار الفحص الخماسي لوثيقة IAEA، محاكي النبضات، حساب FWHM والكفاءة، ومحرك القرارات. |
| **Phase 3: NaI Module & PDF Reports** | فحص كواشف NaI ومحرك تقارير IAEA | فحص NaI(Tl)، توليد تقارير PDF مطابقة لـ IAEA Annex II، تصدير Excel، وطباعة بطاقات الحالة. |
| **Phase 4: Security, Audit & Dashboard** | الأمان وسجل التدقيق والتشطيب النهائي | أدوار المستخدمين، التوقيع الرقمي، قفل الخمول، النسخ الاحتياطي، ولوحة التحكم العامة. |
