# مكتبة المراجع والوثائق الدولية لمنظومة «كاشف» (KASHIF-QA References)

تحتوي هذه المكتبة على كافة الوثائق القياسية الدولية والأدلة الفنية المحملة من خوادم **الوكالة الدولية للطاقة الذرية (IAEA)**، و**المعهد الوطني للبحوث النووية (ININ)**، وشركة **Canberra / Mirion**، والتي تشكل الأساس العلمي والتشغيلي لمنظومة «كاشف»:

---

## 1. سلسلة إجراءات الفحص القياسية (IAEA / ININ MRNI Series)

| اسم الملف | العنوان الفني والوصف | الاستخدام في منظومة كاشف |
| :--- | :--- | :--- |
| **[MRNI-504D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-504D0.pdf)** | **Test Procedure for Scintillation Radiation Detectors**<br>إجراءات فحص كواشف الوميض (يوديد الصوديوم NaI(Tl)). | **المرجع الإلزامي** لمسار فحص كواشف NaI(Tl)، حساب جهد التشغيل $V_0 = (V_M + V_i)/2$، قياس الحساسية، والدقة الطاقية عند قمة السيزيوم-137 ($661.5\text{ keV}$)، واستمارة `TEST REPORT Nº SC`. |
| **[MRNI-507D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-507D0.pdf)** | **Test Procedure for High Purity Germanium Detectors**<br>إجراءات فحص كواشف الجرمانيوم عالي النقاء (HPGe). | **المرجع الأساسي التأسيسي** للمنظومة: المراحل الخمس، فحص التبريد والفراغ، رفع الجهد العالي، قياس FWHM ومعامل الشكل، وحساب الكفاءة النسبية، واستمارة `TEST REPORT Nº HpGe`. |
| **[MRNI-500D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-500D0.pdf)** | **Introduction to Test Procedures for Radiation Detectors**<br>الإطار التمهيدي الموحد لفحص كواشف الإشعاع وسلاسل القياس. | تحديد دورة العمل المعملية ومسؤوليات الفني والمدير، وإدارة التقارير والملصقات. |
| **[MRNI-508D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-508D0.pdf)** | **Test Procedure for High Voltage Power Supplies**<br>إجراءات فحص مجهزات الجهد العالي النووية. | التحقق الفني من استقرار الجهد، ونسبة التموج (Ripple $< 100\text{ mV}$)، ونسبة التنظيم ($< 0.01\%$). |
| **[MRNI-509D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-509D0.pdf)** | **Test Procedure for Preamplifiers**<br>إجراءات فحص واختبار المضخمات الأولية النووية. | فحص جهود سلة NIM، نبضات التغذية بالمقاومة ونبضات الترانزستور (TRP)، وضجيج المضخم. |
| **[MRNI-510D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-510D0.pdf)** | **Test Procedure for Spectroscopy Amplifiers**<br>إجراءات فحص واختبار المضخمات الطيفية. | ضبط الكسب، أزمنة التشكيل ($3-12\,\mu\text{s}$)، وإلغاء الـ Pole-Zero لمنع الـ Overshoot/Undershoot. |
| **[MRNI-512D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-512D0.pdf)** | **Test Procedure for Single Channel Analyzers (SCA)** | فحص وحدات تحليل القناة الواحدة وعتبات التمييز. |
| **[MRNI-513D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-513D0.pdf)** | **Test Procedure for Counters and Timers** | فحص عدادات النبضات النووية والمؤقتات الزمنية. |
| **[MRNI-501D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-501D0.pdf)** | **Test Procedure for Geiger-Mueller Detectors** | كواشف جايجر-مولر (مرجع توسعي مستقبلي). |
| **[MRNI-502D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-502D0.pdf)** | **Test Procedure for Proportional Radiation Detectors** | الكواشف التناسبية (مرجع توسعي مستقبلي). |
| **[MRNI-503D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-503D0.pdf)** | **Test Procedure for Ionization Chambers** | غرف التأين (مرجع توسعي مستقبلي). |
| **[MRNI-505D0.pdf](file:///d:/مشروع%20برنامج%20مراجعة%20كواشف/docs/references/MRNI-505D0.pdf)** | **Test Procedure for Semiconductor Detectors** | كواشف أشباه الموصلات السطحية (Si-Barrier). |
