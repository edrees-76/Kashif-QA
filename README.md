# منظومة «كاشف» لضبط جودة واعتماد الكواشف الإشعاعية ومطيافية أشعة جاما (KASHIF-QA)
## KASHIF: Nuclear Radiation Detector QA/QC & Gamma Spectroscopy System

منظومة برمجية مكتبية متكاملة لضبط الجودة، والمعايرة، والتحقق الفني من كواشف الإشعاع النووي (كواشف الجرمانيوم عالي النقاء HPGe، وكواشف الوميض NaI(Tl)) وفق الإجراءات القياسية المعتمدة من **الوكالة الدولية للطاقة الذرية (IAEA)** (سلسلة MRNI-500 إلى MRNI-513 و IAEA-TECDOC-1599).

---

## 🚀 التشغيل السريع من بيئة نظيفة (Quick Start)

### 1. المتطلبات الأساسية
* نظام التشغيل: Windows 10 / 11 (أو Linux / macOS)
* بيئة بايثون: **Python 3.10+** مثبتة ومتاحة في سطر الأوامر

### 2. إعداد البيئة الافتراضية وتثبيت الحزم
من داخل المجلد الرئيسي للمشروع، نفّذ الأوامر التالية:

```powershell
# 1. إنشاء البيئة الافتراضية
python -m venv .venv

# 2. تفعيل البيئة الافتراضية (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# 3. تثبيت حزم الاعتماديات المعتمدة
pip install -r requirements.txt

# 4. التأكد من سلامة وعدم تعارض الحزم
pip check
```

### 3. تشغيل المنظومة
```powershell
python run.py
```

* **عند أول تشغيل:** ستظهر لك نافذة إعداد أولية لإنشاء حساب مدير النظام (`admin`) وتحديد كلمة المرور، متبوعة بعرض مفتاح الاستعادة الرئيسي للطوارئ (`Master Recovery Key`).
* **في التشغيلات التالية:** ستظهر نافذة تسجيل الدخول المعتادة مع ميزة تذكر اسم المستخدم وقفل الحساب التلقائي بعد 5 محاولات فاشلة.

## 🧪 تشغيل حزمة الاختبارات الآلية (Automated Tests)

لتشغيل كافة اختبارات الوحدة والتكامل مع قياس التغطية:

```powershell
pytest --cov=kashif --cov-report=term-missing tests/ -v
```

## 🏛️ المعمارية والأمان
* **محرك قاعدة البيانات:** SQLite معزول محلياً بنمط الكتابة المسبقة (`PRAGMA journal_mode = WAL`) والقيود الخارجية مفعلة.
* **سجل التدقيق (Audit Ledger):** محمي بسلسلة هاش تشفيرية (SHA-256) مع تريجرز تمنع التعديل والحذف نهائياً.
* **التوثيق:** تجزئة كلمات المرور عبر `Argon2id` (مع بديل `PBKDF2`).
* **الهوية البصرية:** مبنية على لوحة الألوان الرسمية (`docs/visual-identity.md`) مع دعم الوضعين الفاتح والداكن وخطوط عربية رصينة (Tajawal، IBM Plex Sans Arabic، Amiri).
