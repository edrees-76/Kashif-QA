# S5 — الإصدار والتسليم

يبدأ عندما تُغلق كل Phases الـ MVP. الهدف أن يعمل النظام على جهاز
المستخدم الحقيقي، لا على جهاز التطوير فقط.

## قائمة الإصدار

1. **الانحدار:** نفّذ قائمة الطبقة 3 كاملة (S4). أي فشل يعيد للبناء.
2. **النسخ الاحتياطي:** آلية نسخ احتياطي تعمل، و**استعادة مجرّبة فعليًا**
   على جهاز آخر أو مجلد آخر. نسخة لم تُجرَّب استعادتها ليست نسخة.
3. **الحزمة:** مثبِّت أو حزمة نشر حسب المنصة، تُجرَّب على جهاز نظيف (بلا
   أدوات تطوير).
4. **البيانات الأولية:** هل تحتاج ترحيل بيانات من Excel أو نظام قديم؟
   الترحيل يُجرَّب على نسخة أولًا، ويُطابَق العدد قبل/بعد.
5. **الإصدار:** رقم `1.0.0`، وسم Git (بطلب صريح)، و`CHANGELOG.md` محدّث.
6. **دليل المستخدم المختصر:** صفحة أو صفحتان: كيف يدخل، أهم 5 عمليات،
   ماذا يفعل عند خطأ، كيف يأخذ نسخة احتياطية.
7. **التسليم:** جلسة تشغيل مع المستخدم الفعلي (إن لم يكن هو المطوّر)،
   وتسجيل ملاحظاته الأولى كمدخلات S6.
