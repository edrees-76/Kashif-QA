# S0 — فرز الفكرة (قبل الاستجواب الكامل)

الهدف: ألا تُستثمر أسابيع في منظومة كان يكفيها جدول Excel، أو كان مكانها
وحدة داخل نظام قائم. الفرز سريع: خمسة أسئلة، **سؤال واحد في كل مرة**،
وتجاوز أي سؤال أجاب عنه وصف المستخدم الأولي.

## الأسئلة الخمسة

1. **الألم:** كم مرة تتكرر هذه المشكلة، وماذا يحدث اليوم حين تقع؟
   (يكشف هل المشكلة حقيقية ومتكررة أم حالة واحدة.)
2. **البديل الأبسط:** هل جُرّب حلّ بسيط (Excel، نموذج ورقي، أداة جاهزة)؟
   لماذا لم يكفِ؟
3. **التقاطع:** هل تلمس هذه الفكرة بيانات أو عمليات في نظام قائم لديك؟
   (إن نعم: هل الأنسب وحدة داخله أم نظام مستقل مع تكامل؟)
4. **المالك والمستخدم:** من سيستخدمه فعليًا كل يوم، ومن يملك قرار اعتماده؟
5. **الدافع:** هل الدافع حل مشكلة، أم تعلّم تقنية جديدة، أم الاثنان؟
   (مشروع التعلّم مشروعٌ مقبول، لكن يجب أن يُعرَف كذلك ليُخطَّط له بنطاق مناسب.)

## مخرَج S0 — بطاقة القرار

```markdown
# بطاقة فرز: <اسم مقترح>
- المشكلة في سطر:
- التكرار والأثر:
- البدائل التي جُرّبت ولماذا لم تكفِ:
- التقاطع مع أنظمة قائمة:
- المستخدم اليومي / مالك القرار:
- الدافع: حل مشكلة / تعلّم / الاثنان
- الحجم التقديري: صغير (≤3 Phases) / متوسط / كبير
- القرار (G0): ابدأ / أجّل / ادمج في <نظام> / ارفض
- السبب:
```

قدّم توصيتك بالقرار مع سببها، لكن القرار للمستخدم. إن كان "ابدأ"، سلّم إلى
`project-spec-kit` ومرّر له ما عُرف هنا كي لا يُعاد السؤال عنه.
